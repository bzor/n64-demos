## MIDI Stepping Stones

Four musical parts hop across folded faces in time with a stereo soundtrack. Steps slide into place on each hit; sustained notes extend light trails. Eight palettes recolor the scene. The ending reveals a scrambled restart prompt and social links.

- **A** restarts; **Start** pauses.
- **D-pad left/right** changes palettes.
- **D-pad down** opens tuning; **D-pad up** toggles labels.
- **Z** changes the bass note display; **L/R** jumps between song cues.

The default palette is Ion Storm, with the UI hidden and visual sync at −40 ms. The ROM includes all audio and visual assets. It targets NTSC timing and standard 4 MiB memory, with no Expansion Pak or save storage required. Ares v148 checks pass; a physical-console check of this exact version is pending.
