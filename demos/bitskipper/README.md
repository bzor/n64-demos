# bzor BitSkipper v1.0.0-rc1

RECON PROBE sent to a quiet ocean.. Paddle, fly and dive to explore. Discover creatures and enjoy the sunset overlook.


## Play on SummerCart64

1. Download and extract `bzor-bitskipper-v1.0.0-rc1.zip`.
2. Copy `bzor-bitskipper-v1.0.0-rc1.z64` to your SummerCart64 SD card.
3. Launch the ROM from the cartridge menu with a controller in port 1.

## Controls

| N64 control | Action |
| --- | --- |
| Stick | Move / steer |
| A | Confirm menu selection |
| B | Back / resume |
| Start | Advance title screens; pause / resume |
| C-Up | Glide / ascend |
| C-Down | Dive |
| Hold C-Up / C-Down | Ascend / descend underwater |
| Hold C-Left / C-Right | Orbit the camera |
