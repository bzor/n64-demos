# bzor Fibonacci Spikes v1.0.0

An interactive N64 demo with spikes arranged on a Fibonacci sphere. A sine wave drives their height and color.

| N64 control | Action |
| --- | --- |
| Stick | Change the spiral pattern; release to hold the setting |
| Hold Z | Extend the spikes |
| C-Up / C-Down | Increase / decrease wave speed |
| L / R | Decrease / increase spike count, wrapping at the ends |
| A | Restore the default spiral pattern |
| B | Reset wave controls and animation |
| Start | Pause / resume |
| D-pad Up | Show / hide stats |

Extract the ZIP and open the `.z64` in an N64 emulator, or copy it to a SummerCart64 SD card and launch it from the menu.
