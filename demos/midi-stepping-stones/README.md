# bzor MIDI Stepping Stones v1.0.0

Midi parser + visualization of a version of the classic electronic track Popcorn I made in Ableton Live..

## Play on SummerCart64

1. Download and extract `bzor-midi-stepping-stones-v1.0.0.zip`.
2. Copy `bzor-midi-stepping-stones-v1.0.0.z64` to your SummerCart64 SD card.
3. Launch the ROM from the cartridge menu with a controller in port 1.

## Controls

| N64 control | Action |
| --- | --- |
| Stick | In tuning: select row (up/down), change value (left/right) |
| A / B | Restart / replay |
| Start | Pause / resume |
| Z | Toggle full / low bass note display |
| L / R | Previous / next song cue |
| D-pad Left / Right | Previous / next palette |
| D-pad Up | Show / hide labels |
| D-pad Down | Show / hide tuning |
